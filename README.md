# 中国传统算命系统

这是一个基于传统命理学的算命系统,结合现代人工智能技术,为用户提供命理分析和预测服务。

## 主要功能

- 基于传统命理典籍的智能问答
- 八字命盘分析
- 运势预测
- 历史记录查询
- 参数调试
- 多模型支持(GLM-4、MiniMax等)

## 技术栈

- 前端: HTML/CSS/JavaScript
- 后端: Python Flask
- 数据库: SQLite
- AI模型: GLM-4, MiniMax等
- 文本检索: sentence-transformers

## 命理知识库

系统整合了多部重要的命理典籍作为知识库:

- 《渊海子平》
- 《三命通会》
- 《千里命稿》
- 《命理约言》

## 使用说明

1. 启动系统后,点击"开始算命"进入对话界面
2. 在输入框中输入您想咨询的问题
3. 系统会基于命理知识库进行分析并给出回答
4. 可以通过侧边栏功能查看历史记录、调整参数等

## 注意事项

- 本系统仅供娱乐参考,不应作为重要决策依据
- 建议理性对待算命结果
- 保护好个人隐私信息
